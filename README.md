# Munawar Wisdom Framework Generator

A sophisticated web application that generates wealth, wisdom, and lifestyle frameworks using AI-powered analysis.

## Features

- **Comprehensive Framework Generation**: Get structured insights on wealth building, investment behavior, and lifestyle design
- **Mental Models**: Receive relevant mental models for better decision-making
- **Decision Rules**: Actionable rules you can apply immediately
- **PDF Download**: Export your generated frameworks as professional PDF documents
- **Clean, Professional UI**: Minimal design focused on clarity and readability

## Live Demo

Deploy this app to Vercel in minutes!

## Tech Stack

- Pure HTML/CSS/JavaScript
- Claude Sonnet 4 API (Anthropic)
- No dependencies, no build process needed

## Local Development

1. Clone this repository
2. Open `index.html` in your browser
3. Start generating frameworks!

Note: The app uses Anthropic's API which is configured to work automatically in production.

## Deploy to Vercel

### Option 1: Deploy via GitHub (Recommended)

1. **Push to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin YOUR_GITHUB_REPO_URL
   git push -u origin main
   ```

2. **Deploy to Vercel:**
   - Go to [vercel.com](https://vercel.com)
   - Click "New Project"
   - Import your GitHub repository
   - Click "Deploy"
   - Done! Your app is live

### Option 2: Deploy via Vercel CLI

```bash
npm i -g vercel
vercel
```
